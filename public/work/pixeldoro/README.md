# Pixeldoro case study — media assets

Place image and video files in this folder. They are served from `/work/pixeldoro/<filename>`.

| Filename | Usage |
|----------|--------|
| `pixeldoro.webm` | Concept idea |
| `environment.mp4` | Environmental design |

| `128x64-isometric-spritesheet.png` | 128x64 Isometric SpriteSheet |
| `64x64-spritesheet.png` | 64x64 SpriteSheet |

Add PNG or WebP screenshots here and list them in `src/app/games/pixeldoro/pixeldoro-media.ts` as `kind: "image"` entries.
